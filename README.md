# E-commerce Frontend Application

Scalable frontend e-commerce application built with Next.js and TypeScript, focused on real-world user flows, maintainable architecture, and state management.

## 🚀 Features

- Authentication system with persistent sessions (localStorage)
- Protected routes for user-specific pages
- Global state management using React Context API (Auth & Cart)
- Shopping cart with validation (no duplicate items) and total calculation
- Dynamic product listing and individual product detail pages
- Conditional rendering based on user state
- Clean and reusable component structure

## 🛠 Tech Stack

- Next.js (App Router)
- TypeScript
- React
- Tailwind CSS

## 🧠 Architecture & Technical Decisions

- Context API used to avoid prop drilling and manage global state
- Separation of concerns via service layer for API communication
- Persistent session handling with controlled hydration (loading state)
- Modular structure with reusable components
- Client/Server component separation following Next.js best practices
